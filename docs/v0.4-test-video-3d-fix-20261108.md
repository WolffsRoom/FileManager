## User's recording

`CameraRecording-B6A2B870-B66A-45E5-B87C-4976E1EC93F7.mp4` shows a folder entering compressed against the **right half** of the 960x544 display. On returning, a previous page is visible for longer than the intended transition. The issue repeats on different folders and persists beyond the initial animation.

## Root cause and mitigation

The worker thread enumerates directory entries and sends a deferred UI commit when ready. Before this patch, `CommitLoad()` ran `Show(Type_3D_SlideFromFront)` **after** the directory finished loading. The main navigation transition timer starts earlier, in `PushPage()`, and can expire before the directory's results arrive. Thus the incoming folder could enter a separate 3D animation after its parent already finished, leaving a right-half or mis-scaled page.

To prevent this race, the **incoming foreground ListView is always shown full-width**, with `Type_FadeinFast`; the **parent ListView still receives Sony PAF `Type_3D_SlideToBack1`** while the 3D transition is active, and is hidden/reset afterward. This retains the layered 3D background effect for native navigation without letting delayed loading change the foreground's geometry.

The code also avoids passing `auto_delete=true` to PAF `DoReverse()` because `m_retiredPages` owns and later releases that same widget. This prevents duplicate ownership/destruction of an outgoing ListView.

The existing Settings choice **3D nativa / Simples** remains. On 3D the parent background uses PAF native effect; the incoming list uses native fast fade for safety. This is deliberately not identical to every part of v0.2's entry animation.

## Physical PS Vita checklist

1. Open `ux0:` from the device menu. Verify the entire folder occupies the display (no list compressed right).
2. Enter `ux0:app`, back to `ux0:`, and open another folder. Repeat 10+ times and observe the 3D background motion.
3. Repeat with a folder containing hundreds of items, to test delayed directory loading.
4. Return to the main storage menu repeatedly; verify no persistent layers or half-width list.
5. Switch navigation to Simple in Settings; compare stability.
6. If the problem remains, capture the full screen during an open/back cycle, plus note whether it occurs only on the first open or after multiple folders.

**Hardware behavior remains unverified**; compilation and static tests cannot demonstrate correct Sony PAF transitions in the real Vita renderer.
