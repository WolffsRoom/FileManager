## Implemented

- Restored browser page geometry and bounded/recycled PAF Popup1 transitions for large folders; retained native Vita 3D transitions.
- FTP indicator follows runtime state; music icon shows only for minimized playing audio. Alphabetical index uses translucent search icon.
- Image preview arrows respond to touch and the title is near the bottom. Rename and confirmed delete update navigation safely.
- Audio preview offers previous/next, seek-touch animation, embedded cover and fallback artwork.
- Select supports FTP, QR or USB; USB choice is saved (Memory Card / Game Card / SD2Vita / PSVSD). First use without a choice opens the device selector.
- USB uses the taiHEN user-mode ABI and bundled driver. Modal native PAF status identifies device and blocks browsing until disconnect. Eject on PC before disconnecting.
- Settings: icon for selected Select function, font, language, themes, auto-decrypt. Favorite file/folder icons, PSP, music, game formats and suprx icons.
- 230 recognized game/emulator/distribution extensions while preserving special image, VPK and suprx behavior.
