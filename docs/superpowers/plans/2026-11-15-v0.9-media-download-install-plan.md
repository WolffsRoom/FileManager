# FileManager v0.9 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a v0.9 com downloads recebidos por QR, correção segura de PNGs de LiveArea, extração direta de arquivos compactados e preview MP4 nativo funcional no PS Vita.

**Architecture:** O fluxo HTTP passa a separar inspeção de metadados e transferência atômica; a instalação ganha um módulo dedicado a validar/normalizar assets antes da promoção; a modal de informações devolve uma ação explícita para arquivos compactados; e o preview usa um player AvPlayer de três modos baseado na Wolff's Store v0.99.7. A interface ScePaf permanece responsável por modais, progresso, superfícies e navegação.

**Tech Stack:** C/C++, VitaSDK, ScePaf, SceAvPlayer, SceGxm, SceAudioOut, SceHttp, libarchive, libpng, zlib, PowerShell regression checks.

**Spec:** `docs/superpowers/specs/2026-11-15-v0.9-download-vpk-archive-video-design.md`

## Global Constraints

- Versão do pacote: `00.90`; nome visível: File Manager 0.9.
- Downloads finais ficam em `ux0:Downloads`; a transferência usa `<destino>.part` e renomeação atômica.
- A validação TLS permanece habilitada.
- PNG de LiveArea incompatível deve ser corrigido e validado antes do PromoterUtil; arquivo corrompido bloqueia a instalação.
- `SceAvPlayerHandle` válido inclui `0x81xxxxxx`; somente zero e padrão `0x80xxxxxx` são inválidos.
- Ordem de fallback MP4: native GXM, callback GXM, callback CPU.
- Não alterar ou incluir arquivos locais não relacionados já presentes no worktree.

## Review Focus

- URL redirecionada sem extensão mas com `Content-Disposition` deve gerar download com o nome do servidor.
- Falha no meio do download deve remover apenas o `.part`, nunca um arquivo final anterior.
- PNG com transparência deve continuar visualmente transparente depois da paletização.
- Fechar ou trocar o vídeo durante o fallback não pode deixar thread de áudio ou frame GXM em uso.
- ZIP e VPK precisam manter ações e ícones distintos apesar de ambos serem contêineres ZIP.
