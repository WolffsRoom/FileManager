## Crash dump analysis

The three user-provided dumps were inspected as gzip-compressed ARM ELF Vita coredumps:

| Repro | Crash point | Interpretation |
| --- | --- | --- |
| `logs/USB ON/` | FileManager OptionMenu::OptionMenu, R0 = 0 | Null allocation/constructor reached from an active PAF callback. The USB transport itself was not proven to be at fault. |
| `logs/Crash Excluir Favorito/` | FileManager OptionMenu::OptionMenu, R0 = 0 | Same allocator fault while navigating around a removed favorite. |
| `logs/Crash Selecionar/` | ScePaf widget code, R0 = 0 | Likely a stale widget/cell during synchronous Settings list mutation; exact internal ScePaf function is not symbolized. |

All three reports indicate data aborts. This diagnosis is based on the supplied dumps; Vita hardware confirmation of the fixes remains pending.

## Changes

- `OptionMenu::Create`: explicit `nothrow` allocation and incomplete RCO/widget construction guards.
- Defer OptionMenu deletion and event dispatch until after the current PAF button callback; close the menu page without a stale 1000ms transition.
- Back navigation disposes of the old ListView widget, reconstructs the parent ListView and restores canonical 960px size/position after 3D animation. Back action deferred outside the current button event.
- List refresh stages I/O before deleting cells and swaps rows while holding the PAF main-thread lock. Reject stale selection/focus events.
- Shortcuts are maintained after successful rename, move, delete and preview edits, including descendants when a folder is renamed/deleted; invalid root favorites skipped.
- Settings menus change levels via deferred callbacks; unfavoriting removes the row immediately; empty state wraps across multiple lines.
- FTP and music background badges appear only on actual runtime state changes, at the upper left. Music alphabet index disabled.
- `.bin` files use `tex_ui_root` from `resource/ui/lg_root.png`.
- Three native Settings power controls (Power Off, Restart, Sleep), with confirmation, call `scePowerRequestStandby`, `scePowerRequestColdReset`, `scePowerRequestSuspend`, respectively.
- USB storage starts only after loading its status modal and temporarily disallows concurrent FTP. USB diagnostics are written to `ux0:data/FileManager/usb.log` (loading driver, MTP, device path, mass-storage start, cleanup).

## Hardware validation checklist

1. Open multiple nested folders and return: root and subfolders should fill the entire 960px viewport with no right shift.
2. In a folder with many MP3s/photos, scroll repeatedly, open Options, rename a file and select it; watch for `C1-2737-9`.
3. Favorite a photo, delete it in preview, return to root and Settings > Shortcuts. No deleted favorite should be shown.
4. Favorite a photo/folder, rename it, then check that the favorite points to the new path. For folders, nested favorites must follow the renamed parent.
5. Settings > Shortcuts: uncheck one item; it must vanish immediately; an empty list must display the complete multiline text.
6. Start/stop FTP and background audio independently; corresponding badges should only be visible when the service is actually active.
7. Settings > Select Function > USB: select an available storage device, press Select. Inspect `ux0:data/FileManager/usb.log` for step results. **Safely eject the disk on the computer before disconnecting on Vita**.
8. Verify `.bin` uses the native root icon, and Music no longer displays the alphabetical search index.
9. Test the three power actions last. Confirm Cancel does nothing and Yes performs the chosen operation. Do not test during transfers or unsaved work.

**Safety:** Power operations and USB mass-storage access affect system state. The VPK has compiled and passed static regression checks, but remains a beta pending validation on physical hardware.
