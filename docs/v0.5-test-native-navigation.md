# File Manager v0.5 Test - navegação nativa

Build de teste baseada na v0.4 (`aa58cbb`) e comparada com `build/FileManager (alpha).vpk`.

## Alterações

- Corrigido o crash ao abrir **Ajustes**: os checkboxes agora são procurados no item correto e todos os elementos opcionais são validados antes do uso.
- O modo **3D** passou a se chamar **Padrão** e voltou a usar diretamente as transições ScePaf da build alpha.
- O modo alternativo passou a se chamar **Simplificado**.
- Avançar, voltar e restaurar a pasta anterior não usam mais escala, rotação ou temporização manual.
- A barra de seleção ficou mais estreita e preserva o botão `...` visível na frente.
- O estado dos checkboxes foi centralizado para manter a marcação correta inclusive em linhas recicladas durante a rolagem.
- A pesquisa abre no topo e filtra a lista enquanto o texto é digitado, sem fechar o teclado. Enter encerra a edição.
- Metadados internos atualizados para v0.5 Test (`00.50`).

## Validação no PS Vita

1. Abra **Ajustes** e alterne entre **Padrão** e **Simplificado**.
2. No modo **Padrão**, abra três níveis de pastas, role uma lista e volte nível por nível. A pasta anterior deve retornar centralizada e no item que foi aberto.
3. Marque arquivos e pastas, role a lista e confirme que os checkboxes continuam associados aos itens corretos.
4. Confirme que os quatro botões inferiores não cobrem o botão `...`.
5. Pressione Start dentro de uma pasta, digite progressivamente e confirme que a filtragem acompanha o texto a partir do primeiro resultado.

Esta build foi compilada e validada estruturalmente. A aparência e o comportamento final das transições ainda precisam ser confirmados em um console físico.
