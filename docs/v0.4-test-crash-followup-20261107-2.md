## Supplied hardware crash analysis

All three provided dumps are valid gzip-compressed PSP2 ELF cores. In the reported USB and Music crashes, the faulting instruction is a read from R3=0 in the PAF OptionMenu close-button callback (file-relative offset 0x1b20). The prior fix guarded null allocation when constructing the menu, but not a null userdata argument when PAF later called that button handler. This is a narrower, better-supported diagnosis than assuming the USB driver or the Music index caused the crashes. The reported Select crash reaches ScePaf, with BrowserMenu::OnMarkToggle on the stack, consistent with updating row widgets inside the same input event. The exact non-symbolized internal PAF failure cannot be confirmed.

## Code changes

1. Replaced DeferJob on FM::JobQueue with a mutex-protected next-frame queue dispatched by paf::common::MainThreadCallList on the actual UI thread. The previous worker obtained a UI mutex but remained a separate thread, and was running UI page destruction/event callbacks.
2. OptionMenu callbacks reject null userdata/self before any dereference.
3. Selection mutations (Square and long-press), including Select All, are performed on a later UI frame after the original callback returns. They verify the folder is still current.
4. Replaced unstable stack 3D slide with Sony/PAF fast fade. Each folder entry hides all older ListViews; Back reuses its original parent list rather than destroying/recreating it. A popped page still destroys its own list.
5. Power buttons use a dedicated neutral Sony-native textured style with standard touch/focus glow, not a hard-coded purple or other fixed background color.
6. USB start and stop are deferred outside the button handler, and USB status shows a localized Connecting message until a result is returned. Existing device mapping/diagnostic logging retained.

## Physical Vita test order

- Open nested folders, press Circle or touch Back, open a folder again, repeat 10 times: ensure no old/current overlay, 960x544 placement correct.
- Enter ux0:music several times; quickly scroll; use Options, then close; confirm no C1-2737-9.
- Press Square to select an item; long-press another; use Select All and deselect while scrolling.
- Verify the three Settings power buttons show normal gray/native button textures and respond to focus/touch.
- Start USB via Select with FTP stopped. The USB service is NOT yet confirmed functional on hardware. If it fails, save ux0:data/FileManager/usb.log or provide the resulting PSP2 crash dump. Always eject USB from the computer before disconnecting. Avoid testing USB while other apps or file transfers are active.
