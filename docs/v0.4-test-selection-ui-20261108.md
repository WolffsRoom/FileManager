## Changes

- Replaced the hard-coded purple selection bar with a dark neutral overlay matching Vita's native UI.
- Replaced purple selection buttons with neutral native option-menu textures and focus/touch glow.
- Bottom toolbar contains exactly four actions in order: **Select all, Copy, Move, Delete**.
- Action callback dispatch is deferred to the PAF main UI frame for safety.
- File and folder checkboxes are now sibling overlays of their `image_button`, outside the label clipping region. Removed the original duplicate checkbox inside the button.
- File row creation explicitly calls `check->Show(Type_Reset)` when selection mode is active; the checkbox reflects checked/unchecked state for each file.
- Marking one file updates the checked and unchecked indicators on instantiated rows, with null-guard checks for recycled PAF placeholders. Removed the purple row tint.
- Select All updates instantiated checkboxes and no longer rebuilds all file rows.
- Copy/Move saves the selected paths to the existing clipboard, clears selection and closes the selection toolbar; navigate to destination and use Paste.
- Delete uses the existing confirmation dialog; it does not delete without confirmation.
- Circle/Back dismisses an active selection (clears all checks) before navigating up.

## Physical PS Vita test order

1. In `ux0:` or `ux0:app`, press Square (or long-press a file) to enter selection mode.
2. Verify the lower toolbar is **dark/neutral** and contains Select all / Copy / Move / Delete with normal touch/focus glow.
3. Confirm selected and unselected **files and folders** show a checkbox on the right side of their row, no clipping/overlap.
4. Scroll through a long folder while selection is active; newly recycled rows should display correct checks.
5. Use Select All, then deselect some items. Test Circle to clear selection without leaving the directory.
6. Copy two selected items, navigate to another directory and Paste. Repeat with Move.
7. Select several files and press Delete; test Cancel and Confirm paths. Confirm no unintended items are deleted.
8. If any checkbox or native texture remains missing, capture the full 960×544 screen and note which folder, the number of items and whether scrolling occurred.

Changes are verified by compilation and structural regression checks only; native PAF visual behavior must be validated on a physical Vita.
