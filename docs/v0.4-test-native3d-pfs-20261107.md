## Changes

**Navigation:** The original 3D page-behind transition is the default again, using PAF `Type_3D_SlideToBack1`, `Type_3D_SlideFromFront`, and a reverse close on Back. Grandparent lists are hidden; the parent remains as the 3D background. The outgoing page is retained for 24 UI frames, then destroyed outside the input handler. This prevents prematurely destroying a widget that still has a running animation. No duplicated parent ListView is created. Settings > Navigation animation can switch between Native 3D and Simple fade. This choice is persisted as `navigation_3d=1|0` in `ux0:data/FileManager/config.txt`.

**Controls:** Triangle = Search; Start = Options. Touching the lower-right corner continues to open Options. The commands reference inside Settings is updated.

**Music/selection stability:** Browser directory enumeration now happens on its worker thread, but ListView cell mutations and display transitions are committed via a PAF main-thread deferred callback. Large folder rows no longer replay the `Popup1` animation on every recycled item; the device root retains the original row effect. Opening files, selecting, and opening Options have been deferred outside the originating PAF button callback. The existing null userdata checks in OptionMenu remain. The previous crashes were in native PAF callback and widget lifetimes; actual console confirmation is still required.

**PFS decrypted views:** Restored the verified VitaShell/FMVita mount flow. The app attempts the four original VitaShell mount IDs (`0x6E, 0x12E, 0x12F, 0x3ED`) and then `sceAppMgrGameDataMount`; after a successful call, it verifies the mounted directory is readable and populated. The manual Open decrypted action no longer silently opens raw encrypted files after a failed mount and can be attempted in supported PFS container roots even without a `sce_pfs` marker. Patch paths can fall back to the base app title as in VitaShell. All mount attempts are logged at `ux0:data/FileManager/pfs.log`. This feature mounts a **decrypted view**, it does not alter encrypted files in place. Actual mount success varies by firmware, permissions and title.

## Real Vita test checklist (priority order)

1. In **Settings > Navigation animation**, check 3D is the default. Enter folders, Back, Forward and another folder at least 10 times. Verify no overlap/shift; then choose Simple and repeat.
2. Enter `ux0:music`, including a long file list. Rapidly scroll, open/close Options, play a track and return. If it crashes, preserve the new timestamped PSP2 core.
3. Press Square to select/deselect; long-press a file; use Select All. Also test selecting an entry after renaming.
4. Verify Triangle opens Search and Start opens Options. Touch bottom-right remains Options.
5. From `ux0:app`, select a title directory and choose Open decrypted. Inspect the mounted view. Repeat for patch/addcont if available. If unsuccessful, provide `ux0:data/FileManager/pfs.log` and the title path (no personal credentials needed).
6. Verify USB and normal browsing remain unchanged. Safely eject the PC-side USB drive before disconnecting.

No physical hardware test has been run by this build process. Do not classify as stable until the above checks pass.
