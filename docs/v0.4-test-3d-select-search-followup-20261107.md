## Latest Select crash: confirmed fault site

User dump: `logs/Crash Selecionar/Mais atual/psp2core-1794100537-0x0000d82acb-eboot.bin.psp2dmp`.

The dump contains an ARM data abort in ScePaf at `ScePaf + 0x14ce86`, with `r0=0`. The return address in FileManager maps to `BrowserMenu::ApplyMarkToggle(int)` at `FileManager + 0x82e2`. Disassembly confirms the caller had just invoked `paf::ui::Widget::SetColor(...)` after `FindChild(image_button_list_item)`. The code previously checked `GetListItem()` but did **not** check whether that item contained the button. Virtualized/recycled PAF lists can return empty placeholder rows.

Fix: verify both `plane_list_item_check` and `image_button_list_item` exist before mutating selection visuals. Marking remains recorded in the file-entry data even if a specific row is not currently rendered. Selection is ignored while a 3D transition is in progress. Select All now updates actual instantiated rows rather than reconstructing the complete list; Cancel selection clears **all** marked items in a deferred UI pass.

## 3D navigation

- When opening the first folder, never render the root/device menu as a second background layer.
- When opening nested folders, show the immediate parent as a 3D background during the transition only. All grandparents stay hidden.
- At the end of the transition, hide inactive pages and restore their original 960px geometry.
- On Back, no longer call `Hide(Type_3D_SlideToBack1)` on the returning parent; it started another 3D animation and could leave the parent displayed at half width.
- Reset scale, rotation, size and position before showing the parent; clamp them again after the transition timers finish.
- Retain the exiting 3D page temporarily until the reverse animation completes, then release it.
- Settings > Navigation animation still provides Native 3D (default) or Simple fade.

## Settings and Search

- Raised the neutral power-action row and moved the settings list down, giving it a visible gap; list dimensions are kept aligned between RCO and C++.
- Pressing Triangle to search now scrolls the folder to the first row **before** opening the keyboard.
- Filtered results also scroll to the first result, rather than retaining the old scroll offset.
